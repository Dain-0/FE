# BridgeOn (브릿지ON)

지역 창업 정보 플랫폼 | 해커톤 프로젝트 | 2025.11

## 개요
- 기간: 2025.11 (해커톤)
- 팀 구성: 4인 (프론트엔드 2명)
- 내 역할: 프론트엔드 개발

## 담당 역할
- 홈, 창업 네트워크, 창업 정보 페이지 UI 구현
- 배너, 헤더 등 공통 요소를 컴포넌트로 분리해 재사용
- 백엔드 개발자와 API 연동 및 코드 구조 협의
- 작업 충돌 시 변경 사항을 확인하고 병합

## 기술 스택
React, Vite, JavaScript ,TypeScript, HTML5, CSS 등
